# Documentation technique du projet Meshed

Ce dossier contient les documents techniques qui accompagnent le code. Il est lu par les contributeurs et par Claude Code (voir `CLAUDE.md` à la racine du dépôt).

| Document | Contenu |
|---|---|
| `technique/architecture-cible-et-mocks.md` | Architecture « ports et adaptateurs » : contrats P1 à P11, simulations et conditions de bascule |
| `technique/inventaire-socle.md` | Inventaire des composants (infrastructure, données, application, services, outillage), mis à jour dans le même commit que toute modification d'une dépendance |

Toute modification de ces documents passe par une pull request, comme le code.

Les documents de cadrage (règles de gestion, notation, périmètre) et le backlog sont des documents de travail non publiés pour l'instant. Leur publication, sous forme de pages de règles claires, est prévue avant l'ouverture du pilote.
