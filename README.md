# Meshed — agent de sourcing de freelances

Un agent de sourcing de freelances **100 % gratuit et 100 % transparent**, pour les freelances comme pour les recruteurs et cabinets de recrutement.

Principes du projet :

- **Consentement d'abord** : aucune donnée personnelle (téléphone, coordonnées) n'est consultable sans l'accord de la personne concernée.
- **Missions véridiques** : les missions publiées doivent être réelles.
- **Notation actionnable** : freelances, recruteurs, cabinets et clients sont notés sur des critères concrets, qui permettent de s'améliorer.

> Statut : projet en cours de démarrage. Le cadrage est en cours et le code n'a pas encore de version utilisable.

## Transparence sur la fabrication du code

Une grande partie du code de ce dépôt est écrite avec l'aide d'un assistant d'IA, **Claude Code** (Anthropic), sous la direction du porteur de projet. Nous l'indiquons clairement, car la transparence est un principe de ce projet.
